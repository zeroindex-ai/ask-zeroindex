Process

How an engagement works.

Four steps from first email to clean hand-off. No surprises, no lock-in.

00 / Discover

Talk it through.

A 30-minute call. You describe the problem and constraints. I tell you whether ZeroIndex is the right fit — and if not, where to look instead.

Scope it.

A fixed-fee SOW with milestones, deliverables, IP terms, and clear exit conditions — written before any code is.

FAQ

Things you'd ask anyway.

How does pricing work?
Fixed-fee per engagement, set in the SOW before any work starts. Audits are flat-rate. Builds are milestone-based with the fee defined per milestone. No hourly billing surprises, no scope creep without explicit re-scoping.
Do you use AI to write the code?
Yes — heavily. Claude Code is in my hands daily for production code, PR generation, work items, and architecture documentation. But every line that ships is reviewed and tested by a senior engineer (me). Reviewable code, not vibe-coded output.
What if AI isn’t the right tool for the problem?
I’ll say so. Selling an LLM to solve a deterministic problem is the fastest way to lose your trust — and mine. If your problem is better solved by traditional engineering, I’ll either scope it that way or point you to someone who can.
Do you only work with Claude?
Claude-first by design — that’s where I have the deepest experience and where the model lineup is most production-ready. I’ve also shipped on Azure OpenAI and Azure AI Foundry. ZeroIndex does not do foundation model R&D.
What industries do you work with?
Industry-agnostic. The problems ZeroIndex solves — document intelligence, AI in applications, workflow automation, data platforms — apply across verticals.
Are you a solo consultant or a team?
Founder-led, single-engineer studio today. The senior engineer named in your contract is the one writing the code — and the one on-call when it breaks. If ZeroIndex grows, who-does-what is always transparent in the SOW.
